GIT COMMAND CHEATSHEET

1. git commit
Saves staged changes as a new commit.
git commit -m "message" creates a commit with a message.

2. git branch
Lists local branches.
git branch name creates a new branch.
git branch -d name deletes a merged branch.

3. git checkout
Switches branches or restores files.
git checkout main switches to the main branch.
git checkout -b name creates and switches to a new branch.

4. git pull
Downloads and integrates changes from a remote repository.
git pull origin main pulls changes from origin/main.

5. git push
Uploads local commits to a remote repository.
git push origin main pushes the main branch.

6. git merge
Combines changes from another branch into the current branch.
git merge main merges main into the current branch.

7. git rebase
Reapplies commits on top of another base commit.
git rebase main rebases the current branch onto main.

8. git fetch
Downloads remote commits without merging them.
git fetch origin downloads changes from origin.
git fetch upstream main fetches upstream's main branch.

9. git add
Stages files for the next commit.
git add filename stages one file.
git add . stages changes in the current directory and below.

10. git status
Shows the current branch and the state of changed files.
git status -s displays a shorter summary.

11. git log
Displays the commit history.
git log --oneline shows a compact history.
git log -5 shows the five most recent commits.

12. git diff
Shows differences between versions of files.
git diff shows unstaged changes.
git diff --staged shows staged changes.

ADDITIONAL GIT PUSH OPTION

git push -u origin lesson2
Pushes the lesson2 branch to origin and sets its upstream tracking branch.

After this, git push can be used without specifying the remote and branch.
